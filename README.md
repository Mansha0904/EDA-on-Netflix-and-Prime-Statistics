# EDA-on-Netflix-and-Prime-Statistics
An Exploratory Data Analysis (EDA) preformed on the dataset about Movies and TV shows available in Netflix and Prime
📌 Overview
This project focuses on analyzing Netflix’s dataset to extract meaningful insights about movies and TV shows.
The analysis is performed using Python in a Jupyter Notebook.

🎯 Objectives
 Understand Netflix content distribution
 Compare Movies vs TV Shows
 Analyze trends over the years
 Visualize data using charts
📂 Dataset
 File: netflix_titles.csv
 Source: Netflix dataset (public dataset)
 Features:
 Title
 Type (Movie / TV Show)
 Director
 Cast
 Country
 Release Year
 Rating
 Duration
 Genre
🛠️ Tech Stack
 Tool	Purpose
 Python	Programming
 Pandas	Data Analysis
 NumPy	Numerical Operations
 Matplotlib	Basic Visualization
 Seaborn	Advanced Visualization
📊 Exploratory Data Analysis
 ✔️ Steps Performed
 Data Loading & Cleaning
 Handling Missing Values
 Data Inspection (.info(), .describe())
 Data Visualization
 📈 Visualizations
   📊 Countplot of Movies vs TV Shows
   🥧 Pie chart of content distribution
   📉 Trend of releases over years
